# 硬件与验收清单

## 部署前

- [ ] 确认设备为 Raspberry Pi Zero 2 W，运行 64 位 Raspberry Pi OS Lite，并保留可用内存余量。
- [ ] 确认摄像头为 CSI 或 USB，记录分辨率、驱动后端和设备节点。
- [ ] 确认热成像传感器型号、I2C 总线、地址、电源和厂商库；`MLX90640` 仅是当前可选适配器。
- [ ] 确认 CO2 传感器型号、UART/I2C 连接、波特率、校验帧格式和预热要求；`MH-Z19` 是当前可选适配器。
- [ ] 确认麦克风、音响和中文 TTS 程序可用。
- [ ] 确认情绪数据集许可、七类标签映射、模型校验和和安全传输方式。
- [ ] 使用 SSH 密钥认证，禁用口令认证，并轮换任何已暴露的凭据。

运行只读检查：

```bash
sudo deploy/install_pi.sh --check-only
```

检查会报告 arm64、Raspberry Pi OS、Python 3.10、内存、摄像头、I2C、UART 和音频状态。可选接口缺失为警告，但启用相应组件前必须排除该问题。

## 配置与校准

1. 复制 `config/settings.example.yaml` 为本机 `config/settings.pi.yaml`，将 `runtime.mode` 设为 `pi`，按实际组件选择驱动。
2. 将情绪模型路径指向已验证的 ONNX 或 NCNN 文件，输入尺寸不高于 320；用固定光照、单人画面检查七类标签顺序和置信度阈值。
3. 参照 [热成像校准示例](../config/thermal_calibration.example.yaml)，使用已知参考温度调整发射率和偏移。热成像结果是观察值，不应用作临床体温结论。
4. 按 CO2 传感器厂商流程在清洁空气中预热/校准，设置 elevated 和 poor ppm 阈值；验证断连和校验失败不会产生伪读数。
5. 使用无敏感内容的普通话短句验证麦克风、VAD、ASR、智能体和音响链路；断开网络后确认本地提醒和告警仍可用。
6. 将轮换后的智能体密钥写入 `/etc/dorm-assistant/dorm-assistant.env`，设置 `root:dormassistant` 所有者和 `0640` 权限。

## 实机验收记录

完成本机配置后，运行 `check-config`、`self-test` 和受管服务。连续运行至少两小时，记录：模型后端、输入尺寸、采样率、CPU、峰值 RSS、设备温度、推理 FPS、端到端延迟、重启恢复和开机自启结果。报告不得包含完整对话、密码、私钥或 API 密钥。

## 故障排除

| 现象 | 检查顺序 |
| --- | --- |
| 摄像头无帧 | 确认 CSI/USB 后端、`/dev/video0` 或 rpicam 工具、服务账户的 `video` 组和低分辨率设置。 |
| 热成像返回空 | 确认 I2C 已启用、地址/总线、电源、`i2c` 组、Adafruit 库和校准范围。 |
| CO2 无读数 | 确认 UART 已启用、端口/波特率、`dialout` 组、预热时间和帧校验。 |
| 无语音输出 | 确认 `aplay -l`、`audio` 组、TTS 程序、argv 模板和音量设备。 |
| 内存或温度过高 | 降低输入尺寸/FPS/采样率，关闭未用组件，检查交换和散热，再重新记录基准。 |
| 智能体不可用 | 检查网络、已轮换环境变量、超时和契约；不要把授权头或用户对话写入日志。 |

所有实机问题都应先在模拟模式重现控制流，再在维护窗口内使用非敏感测试输入验证硬件修复。
