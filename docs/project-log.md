## 已完成的软件能力

- 定义七类情绪、温度、CO2、提醒、对话和系统快照的数据契约，并提供线程安全状态与有界事件总线。
- 提供本地 YOLO 训练和 ONNX/NCNN 导出入口，固定七类标签顺序，限制树莓派候选模型输入不高于 320。
- 提供视觉、MLX90640 热成像、MH-Z19 CO2、Vosk 输入、系统 TTS 与智能体客户端的可替换接口及 mock 实现；可恢复错误被隔离。
- 融合传感器新鲜度、质量和本地高温/高 CO2 告警；情绪结果仅作为观察，不构成医学诊断。
- 实现提醒持久化、JSONL 隐私过滤、语音对话会话管理、固定线程编排、配置校验、自检命令和模拟端到端场景。
- 提供 Zero 2 W 的部署脚本、非 root systemd 服务、受限环境变量文件模板及运行维护文档。
